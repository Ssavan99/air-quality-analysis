## Files

| File | Rows | Description |
|---|---|---|
| `delhi_aqi.csv` | 18,776 | Hourly observations, 2020-11-25 to 2023-01-24 |
| `biweekly_air_quality_data.csv` | 58 | Fortnightly means, generated by `dataConverter.ipynb` |

Columns in both: `date`, `co`, `no`, `no2`, `o3`, `so2`, `pm2_5`, `pm10`, `nh3`.
All concentrations are µg/m³. There are no missing values in any column.

`biweekly_air_quality_data.csv` is fully reproducible: re-running `dataConverter.ipynb`
regenerates it from `delhi_aqi.csv` byte for byte.

## A note on timestamps

The `date` column carries no timezone. Read as-is, the daily PM2.5 cycle troughs at
09:00 and peaks at 17:00 — inverted for a city, where PM2.5 should be lowest in the
afternoon when the boundary layer is deepest and highest at night when it collapses.
Shifted by +5:30 the trough falls at 14:00 IST and the peak at 22:00 IST, with a
secondary bump at 08:00 for the morning commute, which is the expected shape.

The timestamps are therefore treated as **UTC** and converted to IST for any
time-of-day analysis. See `analysis/seasonality.py`.
